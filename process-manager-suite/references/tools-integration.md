# Tools and Integrations

Tools and platforms used for documenting, analyzing, and managing processes.

## Process Documentation

### Main Tools

**Miro** (recommended for diagrams)
- Visualization of BPMN, SIPOC, Value Stream Mapping
- Real-time collaboration
- Integration with other tools
- Usage: Creating AS-IS/TO-BE diagrams

**Confluence** (if used at the company)
- Documenting processes in text format
- Version control and change history
- Search and navigation
- Usage: Storing SOPs, documentation, audit results

**Google Docs / Microsoft Word**
- Preparing reports and recommendations
- Collaborative editing
- Usage: Drafts, analytical materials

**Visio / draw.io**
- Creating BPMN diagrams
- Exporting to various formats
- Usage: Formal process documentation

---

## Analysis and Metrics

### Tools for Data Collection

**Google Sheets / Excel**
- Collecting and analyzing metrics
- Creating dashboards
- Usage: Tracking KPIs, data analysis

**Power BI / Tableau** (if available)
- Visualizing metrics
- Automated reports
- Usage: Dashboards for leadership

---

## Project and Task Management

### Tracking Tools

**Jira / Linear / Asana**
- Managing implementation tasks
- Tracking progress
- Usage: Action plans, tracking recommendations

**Google Tasks / Todoist**
- Simple task management
- Reminders and deadlines
- Usage: Personal checklists, current tasks

---

## Communication and Synchronization

**Slack / Teams / Telegram**
- Discussing audit results
- Syncing with the team
- Usage: Notifications, discussions

**Google Calendar / Outlook**
- Scheduling meetings and interviews
- Schedule synchronization
- Usage: Coordinating audits, stakeholder meetings

---

## Recommended Workflow

```
1. Gathering information
   ↓
2. Creating diagrams (Miro)
   ↓
3. Analyzing data (Google Sheets)
   ↓
4. Preparing the report (Google Docs)
   ↓
5. Documenting (Confluence)
   ↓
6. Managing implementation (Jira/Asana)
   ↓
7. Tracking metrics (Power BI/Sheets)
```
