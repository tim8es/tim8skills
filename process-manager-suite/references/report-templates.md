# Report Templates

Standard templates for presenting audit, analysis, and recommendation results.

## Template 1: Process Audit Report

```markdown
# Process Audit Report: [Process Name]

**Audit Date:** [Date]
**Auditor:** [Name]
**Process Owner:** [Name]
**Status:** [Draft / Under Review / Final]

---

## Executive Summary

[2-3 sentences about the process condition and key findings]

---

## 1. Process Description

### Current State (AS-IS)
[Brief description of the current process]

### Participants
- [Role 1]: [Responsibility]
- [Role 2]: [Responsibility]

### Inputs
- [Input 1]
- [Input 2]

### Outputs
- [Output 1]
- [Output 2]

---

## 2. Audit Findings

### Strengths
- ✓ [Strength 1]
- ✓ [Strength 2]

### Areas for Improvement
- ⚠ [Issue 1] — Impact: [High/Medium/Low]
- ⚠ [Issue 2] — Impact: [High/Medium/Low]

### Risks
- 🔴 [Risk 1] — Probability: [High/Medium/Low]
- 🔴 [Risk 2] — Probability: [High/Medium/Low]

---

## 3. Recommendations

| # | Recommendation | Priority | Expected Result | Timeline |
|---|---|---|---|---|
| 1 | [Recommendation 1] | High | [Result] | [Timeline] |
| 2 | [Recommendation 2] | Medium | [Result] | [Timeline] |

---

## 4. Action Plan

### Phase 1: Quick Wins (1-2 weeks)
- [ ] [Action 1] — Owner: [Name]
- [ ] [Action 2] — Owner: [Name]

### Phase 2: Medium-Term Improvements (1-3 months)
- [ ] [Action 3] — Owner: [Name]
- [ ] [Action 4] — Owner: [Name]

### Phase 3: Long-Term Initiatives (3+ months)
- [ ] [Action 5] — Owner: [Name]

---

## 5. Success Metrics

| Metric | Current Value | Target Value | Timeline |
|---|---|---|---|
| [Metric 1] | [Current] | [Target] | [Timeline] |
| [Metric 2] | [Current] | [Target] | [Timeline] |

---

## Appendices

- Appendix A: BPMN Diagram AS-IS
- Appendix B: BPMN Diagram TO-BE
- Appendix C: Detailed Stakeholder Interviews
```

## Template 2: Executive Summary

```markdown
# Summary: [Project Name]

**Date:** [Date]
**Prepared by:** [Name]

---

## Key Findings

1. **[Finding 1]** — Impact: [Description of impact]
2. **[Finding 2]** — Impact: [Description of impact]

## Recommendations (Top 3)

1. **[Recommendation 1]** — Expected savings: [Amount/Percentage]
2. **[Recommendation 2]** — Expected savings: [Amount/Percentage]
3. **[Recommendation 3]** — Expected savings: [Amount/Percentage]

## Next Steps

- [ ] Align recommendations with the process owner
- [ ] Develop a detailed implementation plan
- [ ] Assign owners for each action
```

---

## Formatting Guidelines

- **Language:** Clear, professional, jargon-free
- **Structure:** Logical, with clear headings
- **Visualization:** Diagrams, tables, charts where possible
- **Length:** 5-15 pages for a full report, 1-2 pages for a summary
- **Format:** PDF for the final version, Markdown/Google Docs for working drafts
