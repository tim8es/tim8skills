# Roadmap — Video Storycraft

Принцип: скилл для Codex, совместимый со стандартом Agent Skills, — минимальный текстовый процесс без оркестратора, Python/npm, внешних API и отдельных ролей. Каждое усложнение требует измеримого выигрыша.

## V0.1 — завершено в этом PR

- [x] Маршрутизация запросов: идеи / сценарий / производство / ревью / аналитика / полный цикл.
- [x] Проверяемое обещание и сюжет, ориентированный на зрителя.
- [x] Сценарий с речью, кадрами, таймингом и статусом доказательств.
- [x] Минимальный checklist перед записью и публикацией.
- [x] Ручные сценарные smoke-тесты на реальном кейсе и небезопасных утверждениях.
- [x] Совместимый с Codex YAML frontmatter; документированы установка и явный вызов `$video-storycraft`.
- [x] Приватный ChatGPT-плагин v1.0.0 создан из того же `SKILL.md`; независимая установка выполняется пользователем по ссылке.

**Критерий приёмки:** скилл не создаёт фейковых результатов, не выдаёт концепт за готовый ролик, возвращает пригодный для записи текст/кадры и не генерирует ненужные этапы.

## V0.2 — после подключения в ChatGPT/Codex и 5–10 реально снятых роликов

- [ ] Выполнить независимые прогоны скилла внутри ChatGPT и Codex: активация, сценарий, работа с реальными материалами и отказ от неподтверждённых утверждений.

- [ ] Сохранить фактические длительности чтения и обнаруженные проблемы производства.
- [ ] Сопоставить первые секунды, заголовки, CTR и удержание с исходными гипотезами.
- [ ] Устранить повторяющиеся сбои инструкции, не расширяя её без причины.

**Решение о развитии:** обновлять SKILL.md только при повторяемой проблеме хотя бы в двух разных роликах.

## V0.3 — только при подтверждённой необходимости

- [ ] Ввести необязательный шаблон брифа, если пользователь постоянно заново сообщает одни и те же данные.
- [ ] Добавить минимальный скрипт подсчёта длительности/сегментов, если ручная оценка регулярно ошибается.
- [ ] Автоматизировать упаковку и монтаж лишь после появления стабильной схемы исходных материалов.

**Не делать без доказанной пользы:** мультиагентную систему, отдельные файлы на каждый шаг, собственный видеоредактор, обязательную интеграцию с соцсетями, публикацию без проверки.

## Как оценивать результат

- **До съёмки:** доля сценариев, которые можно записать без дополнительных переработок; наличие подтверждений ключевых утверждений; время подготовки.
- **После выпуска:** реальное удержание по участкам, среднее время просмотра, CTR заголовка/обложки, доля досмотревших для сопоставимого формата, переходы/целевые действия.
- **По итогу 5–10 видео:** сравнить с базовой линией по однотипным роликам. Без достаточных данных не объявлять прирост качества или конверсии.
