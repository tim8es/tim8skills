# engineering — scope

In this skill, **engineering** means **software engineering**: writing, reviewing, and refactoring source code — quality, architecture, security, performance, and systems patterns.

- Source code quality (naming, structure, readability)
- Software architecture and design patterns
- Application security (code-level: injection, auth, secrets)
- Runtime performance (algorithms, I/O, memory)
- Systems patterns and operational conventions

**Not covered here:**
- Physical engineering (mechanical, civil, electrical)
- Occupational safety / labor safety
- Hardware or embedded systems
- Infrastructure security (network, physical access)
- Product or business decisions

If a task falls outside this scope, say so explicitly and suggest the user
create a separate skill for that domain.
